# SMF Photo Match

AI-style event photo delivery MVP for SMF Studio.

## Current MVP
- Customer selfie upload flow
- Face-match results gallery UI
- Watermarked/blurred previews
- ₹10 single / ₹30 group pricing
- UPI payment confirmation flow (manual UTR approval)
- Admin upload dashboard UI
- Direct-to-Supabase admin photo uploads
